# غلاف تطبيق آبل (ت2)

الخطة: `docs/appstore/roadmap.md`. هذا المجلد غلاف Capacitor يحمل ملفات اللعبة نفسها داخل التطبيق، ولا يعدّلها ولا يمس الموقع.

## التشغيل على آيفون المالك (على الـ Mac)

يلزم: Xcode، وNode.js 22 أو أحدث، والآيفون موصولاً بكابل مع تفعيل «وضع المطوّر».

```sh
cd app
npm install
npm run sync    # ينسخ ملفات اللعبة إلى www/ ثم إلى مشروع iOS
npm run open    # يفتح المشروع في Xcode
```

في Xcode: الهدف App ← Signing & Capabilities ← Team: حساب Apple ID الشخصي (التوقيع المجاني يكفي، والنسخة تعمل 7 أيام ثم يُعاد التثبيت). ثم اختر الآيفون واضغط ▶.

بعد كل تعديل في اللعبة: `npm run sync` ثم ▶ من جديد.

## ما ضُبط
- الوضع الأفقي وحده، وشريط الحالة مخفي.
- معرّف التطبيق `com.mtech732.bigchallenge` مبدئي، يُثبَّت عند فتح حساب المطوّر (ت4).
- الرقم السري ما زال يُطلب في ت2؛ إزالته في التطبيق وحده تعديل في كود اللعبة لاحقاً (الخطة 5.5).

## تجربة المساعد الصوتي (ت3)

صفحة تجربة داخلية في `app/lab/`، تُنسخ إلى `www/lab/` مع `npm run sync`، ولا تمس ملفات اللعبة ولا الموقع.

- **فتحها:** داخل التطبيق، اضغط على الشاشة بثلاث أصابع ثانية واحدة. «عودة إلى اللعبة» يرجعك.
- **الكود الأصلي:** `ios/App/App/VoiceLab.swift`: تعرّف صوتي بالعربية عبر Speech framework، على الجهاز دون إنترنت إن دعمه الهاتف، وقائمة الموضوع وبدائلها تُعطى للتعرّف تلميحاً.
- **المطابقة:** `lab/match.js`، على تطبيع اللعبة نفسه (`js/modes/auction.js`) مع طيّ الحروف المتقاربة نطقاً.
- **القياس:** يختار المقدّم موضوعاً، ويضغط «اسمع» ويعيد الإجابة بصوته، فيظهر الاقتراح. ثم يحكم «صحيح» أو «خطأ» (أو ينقر العنصر الصحيح). الصفحة تحسب نسبة الاقتراحات الصحيحة وزمنها، و«نسخ النتائج» ينسخها.
- أذونات Info.plist: الميكروفون والتعرّف على الكلام.
- **تطبيق منفصل للتجربة:** على هذا الفرع وحده، المعرّف `com.mtech732.bigchallenge.voicelab` والاسم «تجربة الصوت»، فيبقى تطبيق المالك الأساسي على هاتفه كما هو. يُعاد المعرّف والاسم قبل أي دمج.
