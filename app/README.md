# غلاف تطبيق آبل (ت2)

الخطة: `docs/appstore/roadmap.md`. هذا المجلد غلاف Capacitor يحمل ملفات اللعبة نفسها داخل التطبيق، ولا يعدّلها ولا يمس الموقع.

## التشغيل على آيفون المالك (على الـ Mac)

يلزم: Xcode، وNode.js 22 أو أحدث، والآيفون موصولاً بكابل مع تفعيل «وضع المطوّر».

```sh
cd app
npm install
npm run sync    # ينسخ ملفات اللعبة إلى www/ ثم إلى مشروع iOS
npm run open    # يفتح المشروع في Xcode
```

في Xcode: الهدف App ← Signing & Capabilities ← Team: حساب Apple ID الشخصي (التوقيع المجاني يكفي، والنسخة تعمل 7 أيام ثم يُعاد التثبيت). ثم اختر الآيفون واضغط ▶.

بعد كل تعديل في اللعبة: `npm run sync` ثم ▶ من جديد.

## ما ضُبط
- الوضع الأفقي وحده، وشريط الحالة مخفي.
- معرّف التطبيق `com.mtech732.bigchallenge` مبدئي، يُثبَّت عند فتح حساب المطوّر (ت4).
- الرقم السري ما زال يُطلب في ت2؛ إزالته في التطبيق وحده تعديل في كود اللعبة لاحقاً (الخطة 5.5).
