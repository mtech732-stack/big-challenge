# صيغة ملفات الأسئلة

**الإصدار:** 0.3 · 2026-10-23 · **الحالة:** عُدّلت بطلبات الكاتب الستة، وأكّدها الكاتب (0.3: حدّا الإجابة والبدائل من تصميم ش2، تنبيهين)
**كتبها:** المهندس · **يملك الملفات:** الكاتب (`content/`)، والمالك يعدّل `content/wheel.json`

هذه الصيغة يكتب بها الكاتب البنك كله، وتقرؤها اللعبة كما هي. الأمثلة الكاملة في `docs/content-examples/`، وهي بالبنية نفسها التي سيأخذها `content/`.

---

## 1. بنية المجلد

```
content/
├── packs/
│   ├── index.json            ← قائمة الحزم
│   └── general/              ← الحزمة الثقافية العامة (مجلد لكل حزمة)
│       ├── pack.json         ← اسم الحزمة والأنماط المستثناة
│       ├── letter.json       ← الحرف المعيّن (ومعه أسئلة كسر التعادل)
│       ├── last-two.json     ← آخر حرفين
│       ├── auction.json      ← المزاد
│       └── ranking.json      ← الترتيب
└── wheel.json                ← تحديات العجلة وخانات الحظ (لكل الحزم)
```

- **ملف أسئلة لكل نمط** في كل حزمة. واسم الملف هو معرّف النمط، فلا يُغيَّر.
- **حزمة جديدة** = مجلد جديد بالبنية نفسها، ويُضاف معرّفه إلى `index.json`.
- **نمط تستثنيه الحزمة** لا يحتاج ملفاً، ولا يظهر في اختيار الأنماط حين تُلعب.
- **نمط لم يُكتب ملفه بعد** (البنك يُكتب شريحة بعد شريحة) «غير متاح بعد»: لا يظهر في الاختيار، والفاحص ينبّه ولا يمنع. ولا تُلعب الحزمة قبل نمطين متاحين.

## 2. قواعد عامة لكل الملفات

| القاعدة | التفصيل |
|---|---|
| الصيغة | JSON بترميز UTF-8. الأسماء (المفاتيح) بالإنجليزية كما هي هنا حرفاً بحرف، والقيم بالعربية |
| الأرقام | **إنجليزية** في كل نص (1% لا ١٪). الفاحص يرفض الأرقام الهندية |
| المعرّف `id` | فريد في البنك كله، بحروف إنجليزية صغيرة وأرقام وشرطات. الصيغة المقترحة: `<الحزمة>-<النمط>-<رقم من 3 خانات>`، مثل `general-letter-007`. **لا يُغيَّر بعد النشر**، لأن ذاكرة الأسئلة المستعملة تعتمد عليه |
| المستوى `level` | `easy` (سهل) · `medium` (متوسط) · `hard` (صعب). والترتيب `easy` و`hard` فقط |
| المجال `domain` | واحد من الثمانية في الجدول أدناه |
| رقم الصفحة `page` | **اختياري**، للحزم الدراسية: رقم صفحة الكتاب الذي أُخذ منه السؤال |
| الملاحظة `note` | **اختياري** في كل سؤال وموضوع وقائمة وتحدٍّ: ملاحظة داخلية **لا تظهر في اللعبة** (مصدر المعلومة، سبب قبول إجابة، تنبيه للمدقّق) |
| **الطول** | نص السؤال (`prompt`) وموضوع المزاد (`topic`) **85 حرفاً حداً أقصى** بالمسافات والتشكيل، لأن الشاشة تتسع لثلاثة أسطر بحجم 64 ولا يُصغَّر الخط (نظام التصميم، القسم 7). والفاحص يرفض ما زاد |
| حقل غير معروف | يرفضه الفاحص، ليكشف الأخطاء الإملائية في أسماء الحقول (مثل `anwser`) |

**المجالات (القسم 6.3):**

| `domain` | المجال |
|---|---|
| `kuwait-gulf` | الكويت والخليج |
| `geography` | الجغرافيا |
| `history` | التاريخ |
| `religion` | الدين (في حدود المتفق عليه) |
| `language` | اللغة والأدب |
| `science` | العلوم والطبيعة |
| `sports` | الرياضة |
| `daily-life` | الحياة اليومية |

## 3. ملفات الحزمة

### `packs/index.json`
```json
{ "packs": ["general"] }
```

### `packs/<الحزمة>/pack.json`
| الحقل | معناه |
|---|---|
| `id` | معرّف الحزمة، **يطابق اسم مجلدها** |
| `name` | الاسم الذي يراه المقدّم في الإعداد، ويظهر شارةً على شاشة الجمهور. **30 حرفاً حداً أقصى** (من ش1، design/start.md 2.5) |
| `description` | سطر وصف (اختياري) |
| `excludeModes` | الأنماط المستثناة، من: `letter` · `last-two` · `auction` · `ranking`. فارغة `[]` إن لم تستثنِ شيئاً. ويجب أن يبقى نمطان على الأقل |

## 4. الأنماط

### 4.1 الحرف المعيّن · `letter.json`
```json
{
  "mode": "letter",
  "questions": [
    { "id": "general-letter-001", "level": "easy", "letter": "ش",
      "prompt": "ما تبحث عنه حين يقول هاتفك: البطارية 1%", "answer": "شاحن", "domain": "daily-life" }
  ]
}
```
| الحقل | معناه |
|---|---|
| `letter` | حرف عربي واحد، يظهر في مربع الحرف |
| `prompt` | المطلوب، كما يُعرض للجمهور |
| `answer` | الإجابة النموذجية، يراها المقدّم وحده |
| `alts` | **اختياري**: إجابات أخرى صحيحة يعرفها الكاتب، يراها المقدّم بجوار النموذجية. والمقدّم يقبل غيرها إن انطبقت |
| `tiebreak` | `true` لأسئلة **كسر التعادل** الاحتياطية (صعبة فقط). تُحفظ في الملف نفسه، ولا تظهر في الجولات العادية. ويُحذف الحقل في غيرها |

البنك: 20 لكل مستوى، و20 صعبة لكسر التعادل.

**حدّا نافذة المقدّم** (design/letter.md 2.6، من ش2): الإجابة النموذجية **20 حرفاً**، والبدائل **50 حرفاً مجتمعة** بالفواصل «، ». كي يتسع السؤال والإجابة وأزرار الحكم لحاسوب 1366×768 دون تمرير. الفاحص **ينبّه** على ما زاد ولا يرفضه.

### 4.2 آخر حرفين · `last-two.json`
```json
{ "id": "general-last-two-001", "level": "easy", "ending": "ان",
  "prompt": "صغير الحجم، لكنه يُكرَم به الضيف في كل بيت كويتي", "answer": "فنجان", "domain": "kuwait-gulf" }
```
| الحقل | معناه |
|---|---|
| `ending` | الحرفان **دون تطويل**: `"ان"` لا `"ـان"`. اللعبة تضيف التطويل عند العرض |
| `prompt` · `answer` · `alts` | كالنمط الأول. وأي كلمة أخرى تنطبق تُقبل بحكم المقدّم |

القائمة داخل `"questions": [ ... ]` كالنمط الأول. البنك: 20 لكل مستوى.

**الجولة كلها بنهاية واحدة** (الوثيقة 1.1، 5.4): الأسئلة مجموعات بحسب `ending`، **وكل نهاية فيها سؤالان على الأقل من كل مستوى** (6 أسئلة تكفي جولة). والفاحص يرفض النهاية الناقصة («مجموعة ناقصة»). البنك الحالي 10 نهايات × 6.

### 4.3 المزاد · `auction.json`
```json
{
  "mode": "auction",
  "topics": [
    { "id": "general-auction-001", "level": "easy", "topic": "أشهر السنة الميلادية", "domain": "daily-life",
      "items": [ { "name": "يناير" }, { "name": "فبراير", "alts": ["شباط"] }, …، { "name": "ديسمبر" } ] }   ← مختصر هنا: 12 عنصراً في الملف
  ]
}
```
| الحقل | معناه |
|---|---|
| `topic` | الموضوع كما يُعرض للجمهور |
| `items` | **القائمة المرجعية كاملة**: كل عنصر يظهر زراً في نافذة المقدّم ينقره حين يُذكر |
| `items[].name` | الاسم الأشهر للعنصر |
| `items[].alts` | صيغ بديلة مقبولة **للعنصر نفسه** (اختياري): اسم قديم، أو همزة، أو اسم شائع. لا لعناصر متقاربة. تظهر للمقدّم بجوار الاسم |
| `sources` | **اختياري**: مصادر القائمة المرجعية بصيغة الترتيب نفسها، ليطابقها المدقّق |

الفاحص يرفض تكرار عنصر بصيغة أخرى (مثل «الاثنين» و«الإثنين» عنصرين). **ويرفض القائمة دون 10 عناصر** (المالك، 24 أكتوبر 2026)، لأن المزايدة لا تتحقق دونها. وهذا حدّ أدنى لا هدف: الأفضل قائمة مريحة بعدد يتسع للمزايدة. البنك: 10 لكل مستوى.

**حدّا الشاشة (ش4، design/auction.md 3) تنبيهان لا خطآن:** الموضوع **32 حرفاً** (سطر واحد بجوار العدّ «12 من 12»)، واسم العنصر **20 حرفاً** (شارته). والقائمة الأطول من 30 تُلعب، ويظهر منها بعد الحكم ما يتسع.

### 4.4 الترتيب · `ranking.json`
```json
{
  "mode": "ranking",
  "lists": [
    { "id": "general-ranking-001", "level": "easy", "domain": "sports",
      "title": "الدوري الإنجليزي · الترتيب النهائي لموسم 2025–2026", "asOf": "2026-05",
      "items": [ { "rank": 1, "name": "..." } ],   ← مختصر هنا: 13 عنصراً في الملف الحقيقي
      "sources": [
        { "title": "...", "url": "https://...", "accessed": "2026-10-23" },
        { "title": "...", "url": "https://...", "accessed": "2026-10-23" } ] }
  ]
}
```
| الحقل | معناه |
|---|---|
| `title` | عنوان القائمة كما يُعرض. **والقائمة المرتبطة بزمن تُكتب بتاريخها فيه** (6.4)، والفاحص ينبّه إن غابت سنة `asOf` عنه |
| `asOf` | تاريخ القائمة، **إلزامي** (6.2): `2026` أو `2026-05` |
| `items` | **13 عنصراً بالضبط** مرتبة: 1 إلى 10 الخانات الظاهرة، و11 و12 و13 الفخاخ. `rank` يساوي الترتيب |
| `items[].alts` | صيغ بديلة (اختياري) كالمزاد |
| `sources` | **مصدران على الأقل** متطابقان في الترتيب، لكل منهما عنوان ورابط كامل وتاريخ اطلاع. والمدقّق يطابقهما |

البنك: 10 سهلة و10 صعبة.

## 5. العجلة · `wheel.json`
```json
{
  "challenges": [ { "id": "wheel-001", "text": "نص التحدي كما يُعرض" } ],
  "luck": [
    { "effect": "lose-3", "label": "خصم 3 نقاط" },
    { "effect": "steal-3", "label": "اسرق 3 نقاط من خصمك" },
    { "effect": "gift-3", "label": "هدية: +3 نقاط" }
  ]
}
```
- `challenges`: سبعة تحديات أدائية، ملتزمة بالمحظورات (لا إحراج ولا أذى). يكتبها الكاتب في ش6، ويعدّلها المالك بعدها متى شاء.
- `luck`: ثلاث خانات ثابتة التأثير. يجوز تغيير `label` (النص الظاهر)، ولا يُغيَّر `effect` لأنه ما تنفّذه اللعبة. والقيم نفسها (3 نقاط) مبدئية لا تُغيَّر قبل الشريحة 8.

## 6. الفاحص

قبل كل رفع إلى `content/`، يُشغَّل:

```
node tools/validate-content.mjs content
```

يطبع الأعداد مقابل المطلوب للبنك الكامل، ثم **التنبيهات** (لا تمنع، يراجعها الكاتب بعينه، مثل إجابة لا تبدأ بالحرف المعيّن)، ثم **الأخطاء** (تمنع). والنتيجة الأخيرة «سليم» أو «فشل». واللعبة ستستعمل الفاحص نفسه عند التحميل.

## 7. مراجعة الكاتب وما تغيّر بها

راجع الكاتب الإصدار 0.1 (سجله `docs/logs/الكاتب.md`)، فأُضيف وعُدّل في 0.2:

| # | طلب الكاتب | ما نُفّذ |
|---|---|---|
| 1 | إجابات بديلة في الحرف المعيّن وآخر حرفين | `alts` اختياري، والفاحص ينبّه إن لم تطابق الحرف أو الحرفين |
| 2 | ملاحظة داخلية | `note` اختياري في كل سؤال وموضوع وقائمة وتحدٍّ، لا يظهر في اللعبة |
| 3 | مصادر لقوائم المزاد | `sources` اختياري في المزاد بصيغة الترتيب |
| 4 | سنة `asOf` في عنوان الترتيب | صارت تنبيهاً لا خطأً، ويبقى `asOf` إلزامياً |
| 5 | ملف النمط المفقود | صار تنبيهاً «غير متاح بعد»، ولا يظهر النمط في الاختيار |
| 6 | الفاحص | لا يقبل التطويل «ـ» حرفاً، ويحذف «ال» قبل توحيد الهمزات («ألماس» و«إلكترون» و«ألبانيا» سليمة) |

وأجاب الكاتب بالموافقة على: `alts` البسيطة في المزاد والترتيب، و`tiebreak` داخل `letter.json`، و`ending` دون تطويل، والمعرّفات بثلاث خانات.

**علامة اعتماد الصيغة:** يؤكد الكاتب الإصدار 0.2، ثم يكتب أول ملفين حقيقيين (`content/packs/index.json` و`content/packs/general/pack.json`) فيمرّان على الفاحص «سليم» (مع تنبيه «الأنماط المتاحة الآن 0» المتوقع).
